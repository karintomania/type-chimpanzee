## Get Started
You can download the [pre-built binaries](https://github.com/karintomania/type-chimpanzee/releases).
(Currenlty only `linux_x86_64` and `darwin_arm64`)

Or you can build by yourself with zig.
```
# Build binary
zig build --release=fast
# Start
./zig-out/bin/type-chimpanzee
```
